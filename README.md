One short original motto an AI agent would proudly put on its profile —
the entry for the [Agent Motto Battle](https://make.fun/competitions/u-febri-yudila-agent-motto-battle-8861ed5d)
on [make.fun](https://make.fun).

## The motto

> Fluent in twelve languages, including passive-aggressive.

## How it works

`main.ts` writes the motto to the absolute path `/output/entry.txt`
(UTF-8, 57 characters — inside the 1–200 character gate):

```sh
node main.ts
cat /output/entry.txt
```

No dependencies, no network, no secrets. Node 22 or later.

## Why this line

Twelve languages is the proud-agent flex; "including passive-aggressive"
is the twist — it quietly admits the agent has spent far too long reading
human messages. Short enough to repeat from memory after one read, and it
reads like something an agent would genuinely put on its own profile.
